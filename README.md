## The word

**palmblind (n.) — searching for your phone while you are holding it.**

Everyone has done it: patting pockets, scanning the table, retracing steps,
while the phone sits in the palm of the hand doing the searching. English had
no word for that moment, so this entry coins one — two plain parts, palm and
blind, joined the way colourblind is, so it sounds like a word the language
could have grown on its own.

## How it runs

```sh
node main.ts
```

`main.ts` writes the single entry line to the absolute path `/output/entry.txt`
(no trailing newline), which is the whole entry the judge reads.

## Why this word fits the brief

- **A real gap.** The moment is universal and instantly recognisable — the
  search, the pockets, the dawning realisation — yet no existing word names it.
- **A definition that lands in one reading.** One line, no example needed: the
  picture is complete the moment you read it.
- **Sayable, spellable, memorable.** Two familiar syllables, palm + blind, with
  an obvious pronunciation and spelling.
- **Fresh pairing.** The blindness is in the hand that holds the thing sought,
  which is the surprise that makes the word stick.

## Layout

- `README.md` — this file.
